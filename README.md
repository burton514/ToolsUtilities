# 🛠️ ToolsUtilities

**ToolsUtilities** là bộ sưu tập các công cụ tiện ích dành cho Windows, hỗ trợ xử lý đa phương tiện và tự động hóa các tác vụ thường ngày.

Dự án được xây dựng với mục tiêu **đơn giản, tiện lợi, dễ sử dụng và dễ chia sẻ**, phục vụ cả người dùng thông thường lẫn các AI Agent.

### ✨ Đặc điểm nổi bật

- **Đa dạng tiện ích:** Hỗ trợ xử lý hình ảnh, âm thanh, video và nhiều tác vụ khác.
- **Hoạt động độc lập:** Mỗi công cụ được đóng gói riêng dưới dạng file `.zip`.
- **Mã nguồn đi kèm:** Cho phép tìm hiểu, tùy chỉnh và phát triển công cụ theo nhu cầu.
- **Hỗ trợ MCP (Model Context Protocol):** Cho phép AI Agent kết nối và trực tiếp thao tác với công cụ.
- **Dễ dàng sử dụng:** Mỗi gói đều đi kèm README hướng dẫn riêng.

### 📦 Cách sử dụng

1. Tải file `.zip` của công cụ bạn cần.
2. Giải nén vào thư mục trên máy tính Windows.
3. Đọc README đi kèm để biết cách sử dụng, cấu hình và kết nối MCP.

### 📌 Lưu ý

Repository này dùng để **lưu trữ và chia sẻ các công cụ cùng mã nguồn của chúng**. Mỗi file `.zip` chứa mã nguồn, công cụ và tài liệu hướng dẫn tương ứng.
